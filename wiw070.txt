## 3. CONVENTIONS OBLIGATOIRES POUR TOUT SCRIPT FOURNI
1. Scripts en FICHIERS .ps1 (l'utilisateur execute avec
   powershell -ExecutionPolicy Bypass -File .\x.ps1). Ne jamais supposer
   un collage ligne par ligne.
2. PowerShell 5.1 STRICT (pas de ternaire, pas de ??).
3. Idempotent : detection avant modification, .bak, PREUVE par relecture.
4. Ecriture fichiers : [System.IO.File]::WriteAllText + UTF8Encoding $false
   + normalisation LF. JAMAIS Add-Content en cascade (a casse le README).
5. Kill processus PAR PORT (Get-NetTCPConnection -> Stop-Process Id).
6. Health-checks reels (Invoke-WebRequest 200) plutot que Start-Sleep.
7. Apres modif Java : mvn -q compile + affichage des 10 erreurs si echec.
8. Ordre demarrage : MySQL -> Eureka -> services (x2 si lanceurs) ->
   Gateway EN DERNIER -> Python/Node -> Angular.

## 4. PIEGES CONNUS + CAUSES EXACTES (ne pas refaire)
- 2 instances = instance-id UNIQUE sinon ecrasement (UP(1) avec 2 process).
  Technique : 1 mvn package puis java -jar x2 (--server.port +
  --eureka.instance.instance-id + hostname=localhost). Lanceurs dans
  backend\launchers\ ; si target/ vide -> "Unable to access jarfile"
  -> recompiler + regenerer les lanceurs.
- Dependances inserees avant le DERNIER </dependencies> finissent dans
  dependencyManagement si le pom en a un -> "package does not exist".
  VERIFIER la position dans le pom.
- POYMS actuels a nettoyer (vu dans wiw33) : actuator duplique dans
  dependencies+management (booking, eureka-server) ; loadbalancer dans
  le management du gateway (marche par transitif, fragile) ;
  discovery/pom.xml a {spring-cloud.version} sans $.
- ddl-auto=update NE CORRIGE PAS une table incompatible : DROP puis JPA recreer.
- Bases reelles : nomadix_flight_db / nomadix_booking_db (PAS flight_db).
- URLs pieges : /actuator/gateway/routeS (PLURIEL) ; /api/notifications/
  (avec et sans slash geres) ; hostname Eureka "asus" par defaut
  (corrige par eureka.instance.hostname=localhost).
- Parsing PS des listes JSON (flights, favoris) : propriétés-tableaux ->
  utiliser une fonction Get-List qui reconstruit les objets
  (cf test-openfeign-suite-v2.ps1).
- BUG CONNU NON ENCORE CORRIGE : totalPrice null car booking/FlightDTO a
  origin/destination/price alors que le vrai Flight = flightNumber/
  departureCity/arrivalCity/departureDate/availableSeats SANS price.
  FIX : aligner le DTO (copier celui du traveler-service) + ajouter un champ
  price a l'entite Flight (ou prix par defaut).
- Vol inexistant -> 500 (pas 404) : catcher FeignException.NotFound ->
  ResponseStatusException(404) dans FavoriteFlightService.
- CORS defini 2x (yml globalcors + CorsConfig.java) : redondant mais OK.
- Git : rebase ouvert -> git rebase --abort ; pull --rebase seulement
  working tree clean ; jamais de params PS sur git. README.md : backup
  .safe.bak avant operation. .gitattributes (* text=auto eol=lf) present.
- Fichiers a nettoyer : hs_err_pid*.log / replay_pid*.log dans flight-service
  (~1 Mo), *.bak dans gateway.
